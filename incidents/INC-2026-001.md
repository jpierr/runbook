# INC-2026-001 — Phishing / Account Compromise

**Date:** 2026-03-07  
**Reported by:** Grace Kim (Operations)  
**Affected user:** Bob Singh (Finance)  
**Severity:** High  
**Status:** Resolved  

## Summary
Bob Singh reported he clicked a link in a suspicious email and entered his credentials. Account was immediately disabled pending investigation.

## Timeline
- 20:45 — Grace Kim reports Bob Singh received phishing email
- 20:47 — IT disables bsingh account in Active Directory
- 20:52 — Password reset performed, account re-enabled
- 20:55 — User notified, advised on phishing awareness

## Actions Taken
1. Disabled account: `Disable-ADAccount -Identity bsingh`
2. Reset password via Active Directory Users and Computers
3. Re-enabled account: `Enable-ADAccount -Identity bsingh`
4. Reviewed login history for suspicious activity

## Resolution
Account secured. No lateral movement detected. User completed phishing awareness reminder.

## Lessons Learned
- Implement email filtering rules for external links
- Schedule phishing simulation training for Finance OU
