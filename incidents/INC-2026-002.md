# INC-2026-002 — Account Lockout

**Date:** 2026-03-08  
**Reported by:** Bob Singh (Finance)  
**Affected user:** Bob Singh (Finance)  
**Severity:** Medium  
**Status:** Resolved  

## Summary
Bob Singh was unable to log in after multiple failed password attempts triggered an account lockout.

## Timeline
- 16:15 — Bob Singh calls IT unable to log in
- 16:16 — IT confirms account disabled in Active Directory
- 16:17 — Password reset performed via PowerShell
- 16:18 — Account re-enabled, user confirms access restored

## Actions Taken
1. Confirmed lockout: `Get-ADUser -Identity bsingh -Properties Enabled`
2. Reset password: `Set-ADAccountPassword -Identity bsingh -Reset`
3. Re-enabled account: `Enable-ADAccount -Identity bsingh`
4. Verified access restored

## Resolution
Account unlocked and password reset. User back online in under 3 minutes.

## Lessons Learned
- Consider implementing account lockout threshold policy via GPO
- User advised to use password manager
